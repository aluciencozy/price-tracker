# Bundled artwork and type

JetBrains Mono 2.304 Regular and SemiBold are from
https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf.
The bundled `fonts/OFL.txt` is the SIL Open Font License. No runtime font requests.

Valve game-cover artwork was downloaded once during implementation from these
fixed Steam CDN URLs for the two source-proof games:

- https://cdn.akamai.steamstatic.com/steam/apps/620/library_600x900.jpg
- https://cdn.akamai.steamstatic.com/steam/apps/220/library_600x900.jpg

Portal 2 / Half-Life 2 artwork and trademarks belong to Valve. Used here only to
identify the games in the course prototype; no affiliation is implied. Artwork
is not price evidence. Widgets use local assets with an icon fallback. No
submitted URL, Steam page, price API, or purchase redirect was fetched for art.
