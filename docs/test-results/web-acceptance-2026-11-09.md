## Bug 1 — synthetic API history is presented as real observations

**Severity: medium; initial acceptance failure for fixture-backed history.** At the original snapshot, both game detail pages rendered invented historical values using the same wording and visual treatment as real recorded observations. The page did not identify the history (or the fixture’s current offer) as synthetic. This could mislead a tester or presentation audience into treating invented rows as recorded Steam prices. This initial failure is retained above as historical evidence.

**Resolution and focused retest:** Reviewed test-only fix `c90eb0d` (included in `integration/mvp-completion`) adds a persistent, non-dismissible disclosure outside React and labels the fixture mailbox HTML. On merged snapshot `4237043d353456ea83e4d22799740a19eca3388d`, the disclosure was visible on home, watchlist, Portal 2 and Half-Life 2 details, registration/login/reset/verification routes, and mailbox HTML. Direct watchlist/detail reloads retained it. Both detail histories still showed their three fixture rows and `$9.99` current fixture price, now alongside “All prices and history are synthetic, not recorded Steam prices” and “No real emails or alerts are sent.” The mailbox marker was `fixture: true`; its verification message was generated locally. No fixture purchase link was followed. The banner was outside the React root, had no dismiss controls, and measured 14.05:1 text/background contrast.

Watchlist and both detail pages were checked at 320, 390, 768, and 1440 px: no horizontal overflow, and no banner/action overlap. At 320 px, keyboard focus remained visible through edit/save; Cancel returned to details. The focused fixture-config tests passed (3 tests), and the normal web production build succeeded; a scan of all 17 built files found no QA-disclosure strings. The retest axe audit found zero violations and one incomplete SVG chart-axis contrast check, not a confirmed issue. No new confirmed bug was found. Screenshots are outside Git at `/home/alex/.cache/price-tracker-mvp-browser-qa/retask-c90eb0d/screenshots/`.
